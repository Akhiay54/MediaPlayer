Task 2
Create a simple application that retrieves and displays metadata for videos using a streaming service API of your choice. You must use a non-public API for this task, meaning no use of API keys. You must reverse-engineer an actual API request that a streaming service uses to fetch metadata for a video. The application should:
1. Accept a video ID as input
2. Connect to an appropriate API to fetch the video's metadata
3. Display relevant information about the video (title, description, release date, etc.) Playback not required
Requirements:
   * You may use either Kotlin, Java, or JavaScript for this assignment. A user interface is optional, but the metadata should be clearly presented
   * You must not use a public API. APIs that are not suitable for this assignment include, but are not limited to, the YouTube public metadata API, TMDB, IMDB, etc.
   * Consider using cookies, local storage, or other means of authentication to make these requests
   * Hard-coded values are ok for this assignment as long as you can demonstrate in a video that it works at least once
   * Please record a video of your assignment working and meeting all the requirements


This task is used to demonstrate your ability to reverse engineer programs. Push the code to a git repository and share it along with the submission.
